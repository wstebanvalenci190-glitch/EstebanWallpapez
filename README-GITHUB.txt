ESTEBAN WALLPAPERS — BUILD ON YOUR TABLET

1. Go to github.com and sign in.
2. Create a NEW PUBLIC repository named EstebanWallpapers.
3. Upload ALL files from this folder (including the hidden .github folder).
4. Open the repository's Actions tab.
5. Tap "Build Esteban Wallpapers APK".
6. Tap "Run workflow".
7. Wait for the green check.
8. Open the completed workflow run.
9. Scroll to Artifacts and download "Esteban-Wallpapers-APK".
10. Open the downloaded ZIP, extract app-debug.apk, and tap it to install.

If Android asks, allow Chrome/Files to install unknown apps.
